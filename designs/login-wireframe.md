## User Interaction

1. User opens the application.
2. User sees the login screen.
3. User clicks "Connect with Spotify."
4. User is redirected to Spotify authorization.
5. After successful authentication, the user
   returns to the application.
6. User can access the music search page.

## Error Handling

- Display a message if authorization fails.
- Allow the user to retry connecting.
- Redirect unauthenticated users to login.
